## 🎯 Sobre o Projeto

**PROJECT ARGUS** é um sistema de **Inteligência de Fontes Abertas (OSINT)** para visualização global em tempo real. Agrega dados públicos de aviação, satélites, câmeras, navios, cabos submarinos, terremotos e muito mais em um dashboard unificado.

O nome faz referência a **Argos Panoptes**, o gigante da mitologia grega com cem olhos que nunca dormiam por completo — símbolo da observação perpétua. O projeto ressignifica o mito: em vez de vigilância opressora, propõe **transparência, accountability e análise cidadã** com base em dados abertos.

## ⚖️ Ética e LGPD

O ARGUS trabalha **exclusivamente** com fontes de dados públicas e abertas (OSINT). Não acessa câmeras privadas, dados pessoais ou informações sensíveis sem consentimento. A privacidade é um direito fundamental, e este projeto busca demonstrar que a transparência é possível sem violá-la.
